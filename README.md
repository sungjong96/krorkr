sub4.html 에 적용한 scss 스타일
node.js의 npx 활용한 scss를 css로 바꾸는 방법

1) c드라이브에서 이동이 간편하게 하기 위해 폴더 복사 후 붙여넣기
2) cmd 모드 실행 -> c:\>cd style1 폴더로 이동
3) c:\style1>npx sass css/sub4.scss css/sub4.css 실행 
4) html파일의 head 부분에 <link rel="stylesheet" href="css/sub4.css"> 스타일이 추가
5) 웹화면에서 html문서 실행한다 (컴파일된 sub4.css) 적용화면 확인
